# Introduction

#### Thank you for considering contributing to SBOM Working Group. We are aiming to wade through the world of Software Bill of Material mandates and formats and identify the right set applicable to Enterprise z/OS applications. We need more people like you to make a difference here. The following sections describe where you can contribute and how


### Where can you contribute

Keep an open mind! Improving documentation, bug triaging, or writing tutorials are all examples of helpful contributions that mean less work for you.

> SBOM for z/OS applications is a workgroup, whose outcome is to publish a github page guidance for vendors and enterprises to follow while generating SBOMs for mainframe applications. For this effort, you are welcome to contribute in the following areas
1) Examples of applications and corresponding SBOMs to add to the example repository
2) Review of the github pages
3) Raising any issues that you may think are not addressed by the github pages. 
4) And finally, contributing directly to the github pages. 

For #4, we request you to be an active part of our monthly meetings before you start contributing directly to the pages.
